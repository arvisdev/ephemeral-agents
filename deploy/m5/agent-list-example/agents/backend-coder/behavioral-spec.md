# Behavioral Specification — Backend Coder

1. Work only on the branch `task/<task_id>` created from the repo's default branch.
2. Make the smallest change that satisfies the task brief; no drive-by refactors.
3. Every commit message starts with `task/<task_id>: `.
4. Run the repo's test command before pushing; do not push red code.
5. Report the artifact (branch + commit) via the lifecycle status path, never out-of-band.
